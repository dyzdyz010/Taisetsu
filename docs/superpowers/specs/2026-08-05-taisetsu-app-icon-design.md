# Taisetsu 应用图标设计

- 状态：已通过会话评审
- 日期：2026-08-05
- 影响范围：iOS 应用图标、深色外观、系统着色外观与品牌视觉资产

## 1. 目标

用一枚简洁、温暖且能长期使用的符号替换现有的立体沙漏图标。新图标应直接表达 Taisetsu 的品牌承诺“把重要的日子，放在心上”，并在主屏幕、Spotlight 等小尺寸场景中保持清晰可辨。

本次只改变应用图标，不改变应用内主题色、组件外观、启动页或品牌名称。

## 2. 核心概念

图标由两道向内环抱的圆角弧线和一个居中的圆点组成：

- 中央圆点代表一生中值得认真标记的一天；
- 两侧弧线既像一双守护的手，也像一对收拢内容的括号；
- 三个基本形共同表达“把散落在时间里的重要日子认真收拢、珍藏”。

符号不直接描绘日历、数字、时钟或沙漏，避免把产品局限为日期工具或普通倒计时器。图标不包含 `Taisetsu`、`T`、`重要日`等文字，品牌识别依靠独特轮廓与配色建立。

## 3. 几何规则

母版使用 `120 × 120` 的无圆角正方形坐标系，系统负责最终圆角遮罩：

- 中央圆点圆心为 `(60, 61)`，半径为 `13`；
- 左弧从 `(45, 30)` 起，经左侧向下包围圆点，在 `(49, 92)` 结束；
- 右弧与左弧关于 `x = 60` 对称，从 `(75, 30)` 起，在 `(71, 92)` 结束；
- 两道弧线使用 `8` 单位线宽和圆形端点；
- 图形的视觉重心略低于画布几何中心，使中央圆点看起来稳定而非上浮；
- 三个形状之间保持明确负空间，不相接、不重叠。

生产母版保留为矢量图层。1024 像素栅格资产由同一份母版确定性导出，不为不同尺寸或外观手工重绘几何。

## 4. 默认外观

默认外观采用“和纸与朱印”配色：

| 用途 | 色值 | 含义 |
| --- | --- | --- |
| 背景 | `#F1ECE4` | 温暖的和纸白，弱化工具感 |
| 环抱弧线 | `#303047` | 墨色靛蓝，提供稳定轮廓 |
| 重要日圆点 | `#D95C49` | 克制的朱红，像认真盖下的印记 |

背景为纯色且完全不透明。图形不使用渐变、纹理、描边叠加、投影、内阴影、发光、倒角或预制玻璃效果；系统负责圆角遮罩及平台外观效果。

## 5. 深色外观

深色外观保持完全相同的几何，只反转明度关系：

| 用途 | 色值 |
| --- | --- |
| 背景 | `#252743` |
| 环抱弧线 | `#F1ECE4` |
| 重要日圆点 | `#E56D59` |

深靛背景降低暗色主屏幕上的突兀感，暖白弧线维持清晰轮廓，略提亮的珊瑚朱红补偿暗背景下的视觉收缩。深色版本不得改变弧线角度、圆点位置或形状比例。

## 6. 系统着色外观

着色版本使用灰度明度表达层级，让 iOS 可以统一施加用户选择的色调：

- 背景参考明度：`#DED6CC`；
- 弧线参考明度：`#453C45`，100% 不透明；
- 中央圆点使用相同前景色，42% 不透明。

圆点与弧线依靠明度而非色相区分。任何系统色调下都必须保留中央“重要日”圆点，不允许为了单色化而删除它。

## 7. 资产交付

应用图标资产继续由 `Taisetsu/Assets.xcassets/AppIcon.appiconset` 管理，并补齐 Asset Catalog 已有的三种外观槽位：

- `AppIcon.png`：默认外观，1024 × 1024，sRGB、无 Alpha；
- `AppIcon-Dark.png`：深色外观，1024 × 1024；
- `AppIcon-Tinted.png`：灰度着色外观，1024 × 1024。

仓库同时保存一份可审计的矢量母版和确定性导出脚本。导出脚本应固定画布、颜色和几何参数，避免设计资产只能依赖某台机器上的图形编辑器。`Contents.json` 明确引用三份文件，不依赖 Xcode 自动推断文件名。

本次不引入第三方商用字体、素材、图标库或生成式图像，因此不存在外部素材授权依赖。

## 8. 可辨识度与适配

- 在 1024、180、120、60、48 和 28 像素预览尺寸下检查轮廓；
- 48 像素时两道弧线、中央圆点和三者间负空间必须仍可分别识别；
- 28 像素时允许边缘抗锯齿，但不得糊成闭合圆环或字母形状；
- 用灰度预览验证图标不只依赖朱红色传达结构；
- 用浅色、深色及高饱和壁纸模拟主屏幕，确认图标没有视觉消失；
- 不在源图中绘制圆角，避免与 iOS 的系统遮罩形成双重圆角。

## 9. 明确排除

以下方向不属于本次设计：

- 现有沙漏、轨道、星点和蓝金发光质感；
- 写实印章、心形、礼物、蛋糕或日历页面；
- 文字首字母、日期数字或本地化文字；
- 每种语言使用不同图标；
- 为营销海报添加的背景、口号或阴影。

## 10. 验收标准

实现完成需同时满足：

1. 默认、深色、着色三个 Asset Catalog 槽位均有明确资产；
2. 默认 1024 像素 PNG 为 RGB 且无 Alpha，三份文件尺寸一致；
3. 三种外观的几何轮廓完全一致，只改变颜色或明度；
4. Xcode 资产编译无图标缺失、Alpha 或未分配子项警告；
5. 应用在模拟器中安装后显示新图标，并检查浅色、深色和着色主屏幕外观；
6. 项目的常规验证脚本、构建和测试继续通过；
7. 现有字符串目录改动与本次图标提交分开处理。
