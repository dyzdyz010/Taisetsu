# Taisetsu App Display Name Localization Design

**Date:** 2026-08-04

**Status:** Approved in conversation

## Objective

Localize the name shown below the application icon without changing the Taisetsu brand or any technical identity.

## Display-name matrix

The main application bundle uses these `CFBundleDisplayName` values:

| Locale | Display name |
| --- | --- |
| `zh-Hans` | `重要日` |
| `zh-Hant` | `重要日` |
| `en` | `Taisetsu` |
| `ja`, `ko`, `es`, `fr`, `de`, `pt-BR`, `it`, `ar` | `Taisetsu` |
| Any unsupported locale | Base-value fallback `Taisetsu` |

The non-Chinese values are explicit in the generated String Catalog so the intended English fallback is visible and remains covered by localization validation.

## Identity boundary

Only the main application bundle's localized `CFBundleDisplayName` changes.

The following remain exactly `Taisetsu` or keep their existing Taisetsu-derived identifiers:

- Public brand name and English display name
- `CFBundleName`
- Repository, Xcode project, scheme, target, module, and source names
- Bundle identifiers, App Group, CloudKit container, deep-link scheme, and notification prefixes
- Widget extension bundle name and existing widget configuration metadata

The Chinese icon label is a localized product descriptor, not a technical rename or an alternate global brand.

## Implementation

- Keep `Taisetsu` as the base `CFBundleDisplayName` in `project.yml` and the generated `Taisetsu/Info.plist`.
- Add `CFBundleDisplayName` to the InfoPlist catalog entries generated by `scripts/generate-localizations.swift`.
- Generate `Taisetsu/Resources/InfoPlist.xcstrings` with `重要日` for Simplified and Traditional Chinese and `Taisetsu` for all other supported locales.
- Normalize Xcode's current automatic String Catalog extraction metadata through the repository's deterministic catalog generator.

## Validation

- Add a localization contract check that fails unless both Chinese locales resolve to `重要日` and all other supported locales resolve to `Taisetsu`.
- Confirm the base Info.plist value remains `Taisetsu` for unsupported-locale fallback.
- Run catalog generation drift checks, localization completeness validation, project regeneration, app and widget builds, all unit tests, and coverage enforcement.
- Push directly to `main` and require the CI and CodeQL workflows to complete successfully.
