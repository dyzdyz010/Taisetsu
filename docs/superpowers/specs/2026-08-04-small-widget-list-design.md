# Taisetsu 小号组件多事件列表设计

- 状态：已通过会话评审
- 日期：2026-08-04
- 影响范围：WidgetKit 小号主屏幕组件与共享组件快照

## 1. 目标

将小号方形组件从单事件主视觉改为最多三条纪念日的紧凑列表，让用户无需打开应用即可同时查看最近的多个重要日期，同时保持可读性、独立导航、国际化和无障碍体验。

中号与大号组件继续分别显示最多四条和五条事件，本次不改变其信息层级。

## 2. 内容选取

- 小号组件最多读取三条事件。
- 沿用首页和现有组件的统一排序：置顶事件优先，其余按最近发生时间排序。
- `isVisibleInWidget == false` 的事件不进入快照。
- 只有一条或两条事件时只显示已有事件，不复制、不展示占位行。
- 无事件时继续使用现有空状态。

## 3. 布局与视觉层级

小号组件取消独立标题栏，将可用空间全部用于三行事件列表。每行从左到右包含：

1. 分类图标，使用分类颜色作为有限强调；
2. 单行纪念日名称；
3. 可选的置顶图标；
4. 距离当前时间的本地化相对日期。

名称和相对日期之间保留弹性空间。名称过长时单行截断，相对日期保持单行并获得更高布局优先级。行间使用低对比度分隔线，最后一行不显示分隔线。

小号列表不展示目标日期、重复规则和组件标题；这些信息在有限空间中会压缩事件名称和点击区域，用户可以进入详情页查看。

## 4. 交互

- 每一行都是独立的 `Link`，使用该事件已有的 `taisetsu://anniversary/<UUID>` 深层链接打开对应详情页。
- 有内容时不再给整个小号组件设置只指向第一条事件的 `widgetURL`，避免点击第二、第三行却打开第一条。
- 中号和大号组件的现有点击行为不在本次范围内。

## 5. 国际化与无障碍

- 相对日期继续由系统 `RelativeDateTimeFormatter` 根据当前 Locale 生成，不新增英文缩写或语言特定的紧凑单位。
- 标题与相对日期都限制为一行；标题可以截断，相对日期可以适度缩放以适配较长语言。
- 每行提供组合后的 VoiceOver 标签，包含完整标题、完整相对日期和置顶状态。
- 每行扩展到可用宽度，并保持至少 44 点的点击高度。
- 不仅依靠分类颜色传递信息，分类图标和置顶图标同时保留语义。

## 6. 数据与兼容性

- `WidgetSnapshotFamily.small.capacity` 从 `1` 调整为 `3`。
- 快照 Schema 和 `WidgetEventSnapshot` 字段保持不变，旧快照可直接由新组件读取。
- 快照仍最多保存五条事件，因此无需迁移 App Group 中的已有数据。
- 小号组件的 placeholder 和 preview 提供至少三条示例事件，以便组件图库展示实际列表形态。

## 7. 验证

- 单元测试确认小号、中号和大号分别返回三条、四条和五条事件。
- 保留并验证隐藏过滤、置顶优先及深层链接测试。
- 新增逐行导航所依赖的深层链接覆盖。
- 构建应用和 Widget Extension，运行全部单元测试及现有 CI 验证脚本。
- 对简体中文和较长的拉丁字符示例进行布局检查，确认名称截断不会挤掉相对日期。
